# Roadmap

The following are intentionally not part of the current milestone: authenticated multi-user approvals, concurrent agents, Gemini/Ollama providers, MCP tools, GitHub integration, worktree isolation, pull-request generation, Arena Mode, workflow comparison, agent performance scoring, prompt/version tracking, full replay, provider-side budget reservations, signed audit exports, per-tool user grants, and user-defined executable mission templates.

Each will be proposed in a dedicated design milestone with security, audit, and test requirements before implementation.
