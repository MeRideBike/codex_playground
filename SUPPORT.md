# Support

Use GitHub Issues for reproducible bugs and concrete feature proposals. Please include the operating system, .NET SDK version, and steps to reproduce for technical problems.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and report privately. The issue tracker is not a support channel for security reports.

For architectural questions, read the existing [architecture notes](docs/architecture) and [ADRs](docs/adr) first. If the question is still unresolved, open a discussion or issue with the context needed for others to help.
