# Milestone 8 guided showcase experience

Milestone 8 prioritizes demonstrable product usability over adding new security boundaries. The dashboard opens with a short explanation of the workflow, then presents the four reviewed sample scenarios as selectable cards. Selecting one pre-populates a concrete mission title, objective, sample, and bounded policy so a visitor can start a reproducible mission without learning internal identifiers.

The mission workbench summarizes scenario, sample, progress, and budget before showing the timeline. Detailed audit data remains available behind concise expandable labels rather than dominating the first view. Approval and recovery panels use direct action language: a person can see when a decision is required, what approval releases, and what retry preserves.

The experience was checked through the live local dashboard by starting and approving the security scenario, then inspecting the completed implementation evidence. This milestone does not alter the workflow authority model or add a separate authentication layer.
