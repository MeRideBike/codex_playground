# Milestone 9: Shipping-quality showcase hardening

Milestone 9 makes the guided showcase more trustworthy and more self-explanatory. Requesting a revision now persists its two new run steps explicitly before the workflow resumes, which avoids EF treating them as updates and makes the second approval gate reliable. Integration coverage verifies that behavior through the public API.

The original overloaded calculator sample is split into three focused, allowlisted environments. A completed reviewed mission also exposes the exact before-and-after source content from its isolated application-owned workspace. This is an inspection feature only: it cannot browse arbitrary paths and it does not execute commands.
